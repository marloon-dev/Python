# Desafio 021 — Tocar um MP3

O programa abre e reproduz um arquivo MP3 com a biblioteca [`python-vlc`](https://pypi.org/project/python-vlc/).

O áudio **não é versionado** (direitos autorais e tamanho do repositório). Para testar:

1. Instale o [VLC](https://www.videolan.org/) e a biblioteca: `pip install python-vlc`.
2. Coloque um arquivo MP3 nesta pasta.
3. Ajuste o nome do arquivo em `des021.py` e execute: `python des021.py`.
